# 와글링 (Wagling) — 가족 생활 도구 8종

설치 없이 브라우저에서 바로 쓰는 무료 생활 도구 여덟 가지입니다. 개인정보를 수집하지 않고, 광고도 없습니다.

👀 **바로 열기: <https://starpicklife-design.github.io/>**

## 앱

| 경로 | 앱 이름 | 내용 |
| --- | --- | --- |
| `menu/` | **와글링 테이블** (Wagling Table) | 큰 글씨 메뉴판 계산기 · QR 스티커 · 테이블 이벤트(번호뽑기·당첨/꽝·사다리타기) |
| `elder-menu/` | **어르신용 와글링 테이블** (Wagling Elder Table) | 그림과 큰 글씨로 주문하는 어르신용 주문 화면 |
| `fridge/` | **와글링 장바구니** (Wagling Cart) | 우리 집 냉장고 5칸(냉장·냉동·야채과일·김치냉장고·실온보관바구니) 관리, 영수증 사진으로 품목 넣기 |
| `care/` | **와글링 효도 약통** (Wagling Care) | 어르신 약·물·생활 챙김표, 병원 약 D-Day, 보호자 알림 |
| `dining/` | **와글링 한국여행** (Wagling Korea Trip) | 5개 언어 식당·카페 주문 카드, 그림 메뉴, 주문 연습, 식사 일기 |
| `party/` | **와글링 홀리데이 파티** (Wagling Holiday Party) | 크리스마스 테이블 파티게임 3종(밸런스 게임·60초 이마 게임·고전 명대사) |
| `pronounce/` | **와글링 외국어** (Wagling Language) | 한글 발음으로 익히는 외국어 회화 연습 |
| `fit/` | **와글링 운동** (Wagling Fit) | 가족이 함께하는 짧은 운동 루틴 |

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 와글링 첫 화면 — 8개 앱 카드, `📲 앱으로 설치하기` 안내, `🔗 친구에게 공유하기` |
| `manifest.webmanifest` · `sw.js` · `icon-*.png` · `apple-touch-icon.png` | 첫 화면의 홈 화면 설치 정보·Service Worker·아이콘 |
| `<앱>/index.html` | 앱 본체 (단일 HTML) |
| `<앱>/manifest.webmanifest` (`dining/`은 `manifest.json`) | 홈 화면 설치 정보 — 이름·색·아이콘 |
| `<앱>/sw.js` | 가벼운 Service Worker (화면은 네트워크 우선, 껍데기만 캐시). 아이콘을 바꿀 때는 `CACHE` 이름에 새 접미사를 붙여 기존 설치 사용자도 새 아이콘을 받게 합니다 |
| `<앱>/icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png` | 앱마다 다른 **개별 아이콘** (홈 화면에서 8개가 서로 구별되도록) |

## 메뉴판 기능

- 가게 이름과 메뉴·가격을 넣어 큰 글씨 메뉴판 만들기
- 손님이 휴대폰으로 메뉴를 담으면 사장님 화면에서 총액과 주문 목록 확인
- 매장용 **QR 스티커**(가게 이름 + 메뉴판 주소) 만들어 저장·인쇄
- 메뉴판 사진을 찍어 메뉴 읽어 오기 (사진 인식은 사용할 때만 Tesseract.js를 CDN에서 불러옵니다)

모든 데이터는 방문자 기기의 브라우저 저장소에만 머뭅니다. 서버로 전송되는 값은 없습니다.
