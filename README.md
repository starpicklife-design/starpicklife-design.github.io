# 와글테이블 메뉴판 계산기

설치 없이 브라우저에서 바로 쓰는 무료 메뉴판·계산기입니다. 개인정보를 수집하지 않습니다.

👀 **바로 열기: <https://starpicklife-design.github.io/menu/>**

## 기능

- 가게 이름과 메뉴·가격을 넣어 큰 글씨 메뉴판 만들기
- 손님이 휴대폰으로 메뉴를 담으면 사장님 화면에서 총액과 주문 목록 확인
- 매장용 **QR 스티커**(가게 이름 + 메뉴판 주소) 만들어 저장·인쇄
- 메뉴판 사진을 찍어 메뉴 읽어 오기 (사진 인식은 사용할 때만 Tesseract.js를 CDN에서 불러옵니다)

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 메뉴판 계산기로 가는 안내 페이지 |
| `menu/index.html` | 와글테이블 메뉴판 계산기 (단일 HTML) |

모든 데이터는 방문자 기기의 브라우저 저장소에만 머뭅니다. 서버로 전송되는 값은 없습니다.
