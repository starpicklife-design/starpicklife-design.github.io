# 와글링 명함집 (Wagling Namecards)

내 명함을 목적별로 여러 장 만들고, 받은 명함을 사진으로 담아 두는 **0원 정적 웹앱**.
`https://starpicklife-design.github.io/namecard/`

## 무엇을 할 수 있나요

**🪪 내 명함**
- 일·모임·부업·개인·기타 목적별로 여러 장 추가·수정·삭제
- 이름, 직함/소개, 소속, 전화, 이메일, 홈페이지·SNS, 주소, 한 줄 메모, 프로필/로고 사진
- 디자인 테마 8종(깔끔 화이트·네이비 골드·다크 모던·한국 한지·파스텔 민트·코랄 포인트·올리브 세이지·로열 퍼플) 실시간 미리보기
- `🖼️ 이미지 저장` — 1620×900 고화질 PNG
- `💬 카톡·문자 보내기` — 파일 공유를 지원하면 카톡·문자로 바로, 아니면 이미지 저장 + 안내
- `📱 명함 QR` — 내 명함 정보가 담긴 vCard QR. 상대가 카메라로 찍으면 연락처에 바로 저장. QR 이미지 저장 지원

**📇 받은 명함**
- 명함 실물 사진 찍기/고르기(기기에서 자동 축소) + 이름, 소속, 직함, 전화, 이메일, 메모
- 분류 태그(전체·거래처·병원·돌봄·모임·지인·기타), 이름·소속·메모·번호 빠른 검색
- 카드에서 원터치 `📞 전화` · `💬 문자` · `✉️ 메일`, 명함 사진 크게 보기, `.vcf` 연락처 저장
- 지우기는 확인창 없이 **5초 되돌리기**

**그 밖에**
- `💾 백업` — 내 명함·받은 명함·사진을 JSON 한 파일로 저장/불러오기(합치기)
- `📲 설치`(PWA) · `📤 공유` · `🌐 한/EN` · 폰 뒤로가기 · 큰 글씨·고대비
- 오프라인 동작(서비스 워커), 상단 오늘 날짜·요일·날씨(Open-Meteo, 무료)

## 개인정보

- 모든 명함과 사진은 **이 기기 브라우저(localStorage)에만** 저장됩니다. 서버·DB·회원가입·광고 없음.
- 코드와 예시에는 실제 개인정보가 들어 있지 않습니다. (`김하늘 / 푸른공방`은 가상 예시)
- 사진은 저장 전 기기에서 축소합니다(내 명함 640px, 받은 명함 900px).

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면·스타일 |
| `app.js` | 명함 렌더러(캔버스), 저장·검색·백업·QR·설치 |
| `qr.js` | QR 생성기 — [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 1.4.4 (MIT, Kazuhiko Arase), 오프라인용으로 동봉 |
| `manifest.webmanifest`, `sw.js` | 홈 화면 설치·오프라인 |
| `icon-*.png` | 앱 아이콘 |
