# 💌 와글링 카드꾸미기 — 스스로 꾸미는 카드 만들기 (v3)

해마다 **간지(60갑자)·띠 동물·설날 날짜·D-day·배경 캐릭터·추천 문구가 저절로 바뀌는** 새해·설날,
**크리스마스**, 생일·축하·감사·효도·응원·위로 카드를 직접 꾸며서 **이미지(1080×1440 PNG)로 저장해 카톡·문자로 바로 보내는** 정적 웹앱입니다.

- 위치: `card-maker/` · 라이브 `https://starpicklife-design.github.io/card-maker/`
- 서버·DB·유료 API 없음. 사진·카드는 **이 휴대폰 안(localStorage)** 에만 저장됩니다.
- 100% 자체 제작 SVG(유명 캐릭터·타사 이모티콘 모방 없음). 글꼴은 OFL 무료(Jua·Gowun Dodum·Nanum Pen Script).

## 꾸미기
- 스티커 **끌어서 옮기기**, 한 손가락 **⤢ 손잡이**로 크기 조절, **✕**로 빼기, 맨 앞 스티커부터 선택
- 카드 위 **글씨를 탭하면 글씨 서랍**이 열리고 입력칸에 바로 커서
- 테마별 추천 문구를 **한국어/English** 로 골라 원터치 입력, 직접 고쳐 쓰기
- 글씨체 3종, 색 10종+직접 고르기, 크기 46~120%, 위치 위·가운데·아래
- 긴 문구는 낱말 단위 줄바꿈, 카드 밖으로 넘치면 자동 축소

## 보내기
- `🖼️ 이미지 저장` → Canvas 1080×1440 PNG 다운로드
- `💬 카톡·문자 보내기` → `navigator.share({files})` 지원 기기에서는 공유 창, 미지원이면 저장 후 카톡 첨부 3단계 안내
- 상단 `📲 설치`(PWA beforeinstallprompt + 기기별 안내) · `📤 공유`(앱 링크 공유/복사) · `🌐 한/EN`
- 폰 뒤로가기: 시트 → 꾸미기 → 완성 → 홈 순서. 만들던 카드는 자동 저장되어 `이어서` 가능
