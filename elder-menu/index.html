📲 홈 화면에 앱으로 넣기

아이콘을 한 번 꺼내 두면 앱처럼 바로 열려요.

  1. 카톡·앱 안에서 여셨다면 → 오른쪽 위 ⋮ → 다른 브라우저(Chrome)로 열기
  2. 크롬: 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치)
  3. 삼성 인터넷: 오른쪽 아래 ≡ → 현재 페이지 추가 → 홈 화면
  4. 아이폰·아이패드(사파리): 아래 공유(□↑) → 홈 화면에 추가
